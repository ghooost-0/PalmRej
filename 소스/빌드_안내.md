# PalmRej 소스와 빌드 안내 (1.1.0)

이 폴더는 PalmRej 1.1.0 배포 파일(Releases 의 `PalmRej_1.1.0.zip`)을 만든 소스입니다.
1.1.0 부터 MIT 라이선스로 공개합니다 (저장소 맨 위 `LICENSE`). 1.0.1 이하의 배포 파일은 그때의 사용 조건을 따릅니다.
아래 "MIT 가 적용되지 않는 부분"도 함께 읽어 주세요.

만든 사람은 개발자가 아니고, 아래 방법은 만든 사람 PC 한 대에서만 해 본 것입니다. 다른 PC 에서는 경로나 버전을 맞춰야 할 수 있습니다.

## 폴더

| 폴더 | 내용 |
|---|---|
| `PalmRejFilter` | 손날 인식 필터 드라이버 (KMDF, Wacom 터치·펜·벤더 HID 컬렉션의 위쪽 필터). 판단 코드는 거의 모두 `Driver.c` 에 있습니다. |
| `PalmRejPipeline` | 터치 파이프라인 드라이버 (KMDF, 터치 COL02 의 위쪽 필터). |
| `PalmRawUsbTap` | USB 원시 보고를 읽는 탭 드라이버 (KMDF, USB 장치의 아래쪽 필터, 확장 INF). |
| `패키지_INF` | 1.1.0 배포 zip 에 실제로 들어간 INF 4개 (UTF-16). `PalmRejFilter_Compat` 은 Cintiq Pro 24 가 아닌 와콤 기종용입니다. |
| `관리앱` | "PalmRej 관리" 앱 (.NET 8, WinForms). |
| `설치창` | "PalmRej 설치.exe" (.NET Framework 4.8). `빌드.ps1` 이 `소스\` 를 컴파일합니다. |
| `드라이버 ON-OFF` | 관리 앱의 "PalmRej 켜기 / 끄기" 스크립트 (`ON.ps1`, `OFF.ps1`). |
| `설치 스크립트` | `install.ps1` (설치), `uninstall.ps1` (제거). 설치 창이 이 스크립트를 실행합니다. |
| `출처.txt` | 1.1.0 이 1.0.1 과 무엇이 다른지 적은 기록 (만든 사람 PC 의 폴더 이름이 나옵니다). |

- 각 드라이버 폴더의 `.inf` 는 개발할 때 쓰던 것이라 이름·설명이 다르고, `PalmRejPipeline.inf` 는 KMDF Verifier(디버깅 기능)를 켭니다. 배포판에는 쓰지 않았습니다. 패키지는 `패키지_INF` 의 INF 로 만드세요.
- 필터의 `Device.c`, `Queue.c` 는 템플릿이 만든 파일이고 빌드에 쓰지 않아서 넣지 않았습니다. 그래서 `출처.txt` 의 "나머지 9개 파일" 가운데 7개만 이 폴더에 있습니다.

## 필요한 도구

- Windows 10/11 x64
- Visual Studio (C++ 데스크톱 개발) + Windows Driver Kit (WDK)
  - 만든 사람: Visual Studio 18 Community, MSVC 14.51, WDK 10.0.28000.0, KMDF 1.15
- .NET 8 SDK (관리 앱)
- .NET Framework 4.8 (설치 창): 4.8.1 참조 어셈블리와 Visual Studio 에 들어 있는 Roslyn `csc.exe` 를 씁니다.

## 드라이버 빌드

"Developer PowerShell for VS" 에서 이 폴더로 가서 실행합니다.
Git Bash 에서는 `/t:` 의 `/` 가 바뀌어 빌드가 되지 않습니다.

```powershell
msbuild PalmRejFilter\PalmRejFilter.vcxproj     /t:Rebuild /p:Configuration=Release /p:Platform=x64 /p:SignMode=Off
msbuild PalmRejPipeline\PalmRejPipeline.vcxproj /t:Rebuild /p:Configuration=Release /p:Platform=x64 /p:SignMode=Off
msbuild PalmRawUsbTap\PalmRawUsbTap.vcxproj     /t:Rebuild /p:Configuration=Release /p:Platform=x64 /p:SignMode=Off
```

- 결과는 각 폴더의 `x64\Release\*.sys` 입니다. 서명은 아래에서 따로 합니다.
- 프로젝트는 위처럼 하나씩 따로 빌드하세요. 필터와 탭의 `.vcxproj` 는 같은 템플릿에서 나와 `ProjectGuid` 가 같으므로, 한 솔루션에 함께 넣으면 충돌합니다. 프로젝트에 적힌 `ReadMe.txt`, `README_PV1F.txt` 는 빌드에 쓰지 않는 메모라 넣지 않았습니다 (없어도 빌드에는 영향이 없습니다).
- 파이프라인의 Release 설정은 경고를 오류로 처리하고 PREfast 검사도 켭니다. 다른 WDK 버전에서는 새 경고 때문에 멈출 수 있습니다.
- 만든 사람 PC 에서는 끝의 InfVerif / ApiValidator 단계 때문에 종료 코드가 1 이었습니다. `.sys` 가 새 시각으로 만들어졌는지 직접 확인하세요.
- 필터 `.sys` 에는 빌드 이름 `PalmRej-1.1.0` 이 들어갑니다 (`Driver.c` 35614, 35682 줄).

## 서명: 반드시 자기 인증서로

- 만든 사람의 서명 인증서(`CN=PalmRej Test Signing`)의 개인 키는 공개하지 않습니다. 직접 빌드한 드라이버는 **자기 테스트 서명 인증서를 새로 만들어** 서명하세요. 다른 사람의 인증서나 개인 키를 받아 쓰지 마세요.
- 자기 인증서의 개인 키(`.pfx`)는 저장소나 zip 에 절대 넣지 마세요. 이 인증서를 믿도록 등록한 PC 는 그 키로 서명된 드라이버를 모두 실행합니다.

```powershell
$cert = New-SelfSignedCertificate -Type CodeSigningCert -Subject "CN=My PalmRej Test" `
        -CertStoreLocation Cert:\CurrentUser\My -HashAlgorithm SHA256 -NotAfter (Get-Date).AddYears(5)
$t = $cert.Thumbprint
```

패키지 폴더는 배포 zip 과 같은 모양으로 만듭니다.

```
패키지\PalmRejFilter\         PalmRejFilter.sys   + 패키지_INF\PalmRejFilter\palmrejfilter.inf
패키지\PalmRejFilter_Compat\  같은 PalmRejFilter.sys + 패키지_INF\PalmRejFilter_Compat\palmrejfilter.inf
패키지\PalmRejPipeline\       PalmRejPipeline.sys + palmrejpipeline.inf
패키지\PalmRawUsbTap\         PalmRawUsbTap.sys   + PalmRawUsbTap.inf
```

1. INF 의 `DriverVer` 줄을 새 날짜와 번호로 바꿉니다 (예: `10/02/2026,1.1.0.0`). `install.ps1` 은 이 번호로 옛 판을 가려 내므로, 번호는 이미 설치된 판보다 커야 새 판으로 바뀝니다.
   날짜는 UTC 기준으로 오늘이거나 그 전이어야 합니다. Inf2Cat 은 기본으로 UTC 시각과 비교해서, 날짜가 미래면 카탈로그를 만들지 않고 멈춥니다 (한국 시간 오전 9시 전에 그날 날짜를 넣으면 이렇게 됩니다). 내 PC 의 날짜로 비교하게 하려면 Inf2Cat 에 `/uselocaltime` 을 붙이세요.
2. 폴더마다 `.sys` 서명 → 카탈로그 만들기 → 카탈로그 서명 (도구는 `C:\Program Files (x86)\Windows Kits\10\bin\<버전>\x86\` 에 있습니다).

   ```powershell
   signtool sign /fd SHA256 /sha1 $t 패키지\PalmRejFilter\PalmRejFilter.sys
   Inf2Cat /driver:"패키지\PalmRejFilter" /os:10_X64
   signtool sign /fd SHA256 /sha1 $t 패키지\PalmRejFilter\palmrejfilter.cat
   ```

3. 인증서의 공개 부분만 내보냅니다. `인증서` 폴더를 먼저 만듭니다.

   ```powershell
   New-Item -ItemType Directory -Force 인증서 | Out-Null
   Export-Certificate -Cert Cert:\CurrentUser\My\$t -FilePath 인증서\내_인증서.cer
   ```

## 테스트 모드

- 테스트 서명 드라이버는 Windows 테스트 모드에서만 실행됩니다. 보안 부팅(Secure Boot)을 끄고, 관리자 권한으로 `bcdedit /set testsigning on` 을 실행한 뒤 재부팅합니다.
- `install.ps1` 은 테스트 모드 켜기와 `인증서\*.cer` 등록(로컬 컴퓨터의 Root, TrustedPublisher)을 스스로 합니다.
- BitLocker 를 쓰면 부팅 설정을 바꾸기 전에 보호를 한 번 멈추세요 (`install.ps1` 은 스스로 합니다). 그러지 않으면 다음 부팅에 복구 키를 묻습니다.

## 관리 앱과 설치 창

```powershell
# 관리 앱 (관리앱 폴더에서) -> out\PalmRejFilterManager.exe (배포판에서는 "PalmRej 관리.exe")
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true `
  -p:DebugType=none -p:DebugSymbols=false -p:Version=1.1.0 -p:FileVersion=1.1.0.0 -p:AssemblyVersion=1.1.0.0 `
  -p:EnableCompressionInSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o out

# 설치 창 (설치창 폴더에서) -> 빌드\PalmRej 설치.exe
.\빌드.ps1 -Version 1.1.0
```

`빌드.ps1` 의 `csc.exe` 와 참조 어셈블리 경로는 만든 사람 PC (Visual Studio 18 Community, .NET Framework 4.8.1) 에 맞춰 적혀 있습니다. 다르면 그 두 줄을 고치세요.

## 배포 폴더 모양 (`install.ps1` 이 기대하는 것)

```
PalmRej 1.1.0\
  install.ps1
  PalmRej 설치.exe
  패키지\        (위의 4 폴더)
  인증서\        자기 인증서의 .cer 하나만 (공개 부분만)
  프로그램\      PalmRej 관리.exe, PalmRejFilterManager.ico, uninstall.ps1, PalmRej 설치.exe,
                 드라이버 ON-OFF\ON.ps1, 드라이버 ON-OFF\OFF.ps1
  읽어보세요.txt, 라이선스\   (배포 zip 에서 가져오세요)
```

- `.ps1` 은 UTF-8 BOM 으로 저장해야 Windows PowerShell 5.1 이 한글을 제대로 읽습니다.
- 자기 인증서로 만들 때 고칠 곳 (만든 사람 인증서가 적혀 있음):
  - `드라이버 ON-OFF\ON.ps1` 의 인증서 지문 `02917AB8…` 한 줄. 그대로 두면 켜기의 "패키지에 쓰던 빌드 넣기" 단계를 건너뜁니다.
  - `설치 스크립트\uninstall.ps1` 의 `CN=PalmRej Test Signing` 한 줄. 그대로 두면, 첫 설치가 중간에 실패한 뒤 다시 설치한 PC 에서 제거할 때 인증서가 남습니다.
  - `install.ps1` 은 `인증서\` 의 `.cer` 과 서명자가 같은지만 보므로 고칠 것이 없습니다.
    다만 `인증서\` 에는 자기 `.cer` 하나만 두세요. `install.ps1` 은 이름순으로 첫 `.cer` 하나만 읽으므로, 배포 zip 의 `PalmRej_서명인증서.cer` 가 함께 있으면 "패키지 서명자가 함께 든 인증서와 다릅니다" 로 멈춥니다.

## 만든 사람의 빌드 폴더 (왜 경로 길이를 고정했나)

배포된 드라이버는 아래 폴더에서 빌드했습니다.

- 필터: `C:\PalmRejBuild\PalmRejFilter-1.1.0-public-build-000…000\W` (0 이 49개, 경로 100자)
- 파이프라인: `C:\PalmRejBuild\PalmRejPipeline-1.0.0-public-build-000…000\P` (0 이 48개, 경로 101자; 1.0.0 부터 같은 `.sys`)
- 탭: `C:\PalmRej_A460_20260831_233739_554\RawTap` (2026-08-31 빌드; 1.0.0 부터 같은 `.sys`)

빌드 폴더 경로는 `.sys` 안에 문자열로 들어갑니다 (WDF 매크로의 `__FILE__`, `.pdb` 경로).
경로 길이가 바뀌면 그 뒤의 데이터 주소가 밀려서, 판끼리 바이트·디스어셈블리로 비교할 때 진짜 코드 차이만 골라낼 수 없습니다.
그래서 옛 판과 길이가 같은 폴더 이름을 쓰고, 사용자 이름이 들어가는 사용자 폴더 밑에서는 빌드하지 않았습니다.
같은 경로·같은 도구로 빌드해도 빌드 시각, 디버그 번호, 체크섬, 서명은 다르게 나옵니다.

확인한 것: 이 폴더의 필터·파이프라인 파일은 위 빌드 폴더의 같은 이름 파일과 바이트까지 같고, 배포된 두 `.sys` 는 그 폴더의 빌드 결과와 체크섬·서명 말고는 같습니다.
`Driver.c` 의 SHA-256 (git 이 줄 끝을 바꾸면 달라집니다):

- `PalmRejPipeline\Driver.c` 921BFCB495AA2745F9039FD8D6BEBD260E59FB60BA5F4362B54D16A399C1DA61

## MIT 가 적용되지 않는 부분

MIT 는 만든 사람이 쓴 부분에만 적용됩니다.

- `PalmRejFilter` 와 `PalmRawUsbTap` 의 `Device.h`, `Public.h`, `Queue.h`, `Trace.h`, 그리고 세 `.vcxproj` 의 뼈대는 Visual Studio / WDK 의 KMDF 드라이버 템플릿이 만든 것입니다 (파일 머리의 "Module Name / Abstract / Environment" 주석, `.vcxproj` 의 `TemplateGuid`). 파일에 저작권 표시는 없지만 만든 사람이 쓴 것이 아니므로, Microsoft 템플릿에서 나온 이 부분은 MIT 범위에 넣지 않습니다.
- 빌드에 쓰는 WDK·.NET 의 헤더와 라이브러리는 이 저장소에 없습니다. 각자 설치한 Microsoft 도구의 조건을 따릅니다.
- 관리 앱 exe 에 함께 묶이는 .NET 런타임은 MIT 라이선스이고, 고지문은 배포 zip 의 `라이선스\` 에 있습니다.
- 개인이 만든 비공식 프로그램이며 Wacom 과 관계가 없습니다. Wacom, Cintiq 은 Wacom Co., Ltd. 의 상표입니다.

## English (short)

- This folder is the source of PalmRej 1.1.0. From 1.1.0 on it is released under the MIT License (see `LICENSE` at the repository root); releases 1.0.1 and earlier keep the terms they shipped with.
- Drivers: Visual Studio + WDK, `msbuild <project> /t:Rebuild /p:Configuration=Release /p:Platform=x64 /p:SignMode=Off`. App: .NET 8 SDK (`dotnet publish`). Setup window: .NET Framework 4.8 (`설치창\빌드.ps1`).
- Sign with **your own** test-signing certificate. The author's private key is not published; never use someone else's key, and never commit a `.pfx`. Use the INFs in `패키지_INF`, then `signtool sign /fd SHA256`, `Inf2Cat /os:10_X64`, and sign the `.cat`. The `DriverVer` date must not be in the future in UTC (or pass `/uselocaltime` to Inf2Cat). Put only your own `.cer` in `인증서\`. The drivers load only in Windows test-signing mode (Secure Boot off).
- The author built the filter and pipeline in fixed-length folders under `C:\PalmRejBuild` so that builds can be compared byte by byte (the build path is embedded in the `.sys`).
- The KMDF template files (`Device.h`, `Public.h`, `Queue.h`, `Trace.h`, project skeletons) come from Microsoft's WDK templates and are not covered by the MIT grant.
- Unofficial; not affiliated with Wacom.
